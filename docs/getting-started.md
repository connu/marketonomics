# Getting Started

## Prerequisites

- Node.js (Node 20+ recommended)
- npm

## Install and run

```bash
git clone <repo-url>
cd marketonomics
npm install
npm run dev        # starts the dev server at http://localhost:3000
```

Other commands:

```bash
npm run build      # production build
npm start          # serve the production build
npm run lint       # ESLint
```

Opening `http://localhost:3000` redirects you to `/economics`, the Relationship Explorer. The top navigation switches between the app's two tabs. A chart-design toggle lets you switch between the classic light design and a TradingView-inspired dark mode.

> **Note:** the app fetches live data from Yahoo Finance through its own API routes, so you need an internet connection. If Yahoo's unofficial API is down or rate-limiting, stock search and loading will fail (see [Limitations](limitations.md)).

## Tab 1: Relationship Explorer (`/economics`)

This is the main analysis page. The workflow:

### 1. Search and load a stock

Type a ticker or company name into the search box (e.g. `AAPL`, `NVDA`, `SPY`). Suggestions come from Yahoo Finance's search endpoint, filtered to equities, ETFs, and indices. Pick one and click **Load Chart**. The app fetches the symbol's full available price history once and caches it, so changing factors or the year range afterwards does not re-fetch.

### 2. Choose a year range

Once a chart is loaded, a **5Y / 10Y / 15Y / 20Y** toggle appears (default: 10Y). This sets the analysis window. Keep in mind that with annual data, "10Y" means roughly 10 data points — a very small statistical sample.

### 3. Select factors

The **Select Factors to Overlay** panel at the bottom lists 21 factors grouped into six categories: Monetary Policy, Market Indices, Commodities, Technology, Macroeconomic, and Climate. Click a chip to toggle it on or off. Selected factors appear as colored chips above the chart and as extra lines on it.

### 4. Read the overlay chart

The chart plots the stock (solid dark line) against each selected factor, one point per year. Because the series have wildly different units (%, $/oz, index points…), they are normalized for display. A toggle picks the mode:

- **Z-Score** (default) — each series is centered on its own mean and scaled by its own standard deviation. Best for comparing shape and timing.
- **% Change** — cumulative percent change from the first year in the window. Fast-growing series will dominate the axis.
- **Min-Max** — each series scaled to 0–100 within the window.

Hovering shows both the normalized value and the raw value with its unit.

### 5. Read the statistical results

When at least one factor is selected, a **Statistical Analysis** card grid appears. It runs **all ten methods at once** — Pearson, Spearman, cross-correlation, linear regression, rolling correlation, Granger causality, cointegration, Monte Carlo, elasticity, and mutual information — and shows one card per method with the headline number and a one-sentence explanation. Each card expands to show a rolling-window breakdown.

Two things to be aware of:

- The card grid analyzes the stock against the **first selected factor only**. Adding more factors adds them to the chart overlay, but the stat cards stay pinned to the first one. To analyze a different factor, deselect factors so it comes first.
- There is no method picker on this page — you get all ten methods together rather than choosing one. (A tabbed method-selector component exists in the codebase but is not currently wired into the page.)

See [How It Works](how-it-works.md) for what each method means, and [Limitations](limitations.md) for why p-values on ~10 annual observations deserve heavy skepticism.

### 6. The "Research Summary" panel

Below the cards is a Research Summary box with an "AI · GENERATED" badge. **Be aware: this text is a fixed template.** It is not generated by an AI and does not change based on your results — only the ticker, factor names, window, and sample size are substituted in. The "Confidence: High" chip is decorative. Treat this panel as boilerplate, not as an interpretation of your data.

## Tab 2: Comparative Analysis (`/analytics`)

This tab compares series against each other over the full 2004–2025 annual dataset (no stock loading step needed for factors).

- **Synchronized Time Series** — a grid of mini-charts, one per selected series. Hovering one chart cross-highlights the same year in all of them. Remove a series with the × that appears on hover; add more with **Add Graph**. Six factors are preselected (S&P 500, AI investment, Fed funds rate, CPI inflation, WTI oil, gold). You can also add stock tickers as comparison series alongside the bundled factors.
- **Relationship Matrix** — a Pearson correlation heat map across all selected series. Blue = positive, red = negative.
- **Pairwise detail drawer** — click any off-diagonal cell to open a side panel with: Pearson r and R², a scatter plot with the OLS regression line, cross-correlation at lags −2 to +2 years, and a short written interpretation. Note that this interpretation is also template text keyed off the size of r, not a bespoke statistical report.

## Portfolio data (import/export)

The codebase includes a portfolio module (`src/features/portfolio/`) for tracking holdings:

- Holdings live entirely in your browser's **localStorage** under the key `quantlab_holdings_v1`. Nothing is sent to any server.
- **Export** downloads your holdings as a JSON file named `quantlab-portfolio-YYYY-MM-DD.json`.
- **Import** reads a JSON file containing an array of holdings and validates each entry; invalid entries are silently dropped.

A holding record looks like:

```json
{
  "id": "uuid",
  "company": "Apple Inc.",
  "ticker": "AAPL",
  "shares": 10,
  "purchasePrice": 150.0,
  "currentPrice": 190.0,
  "sector": "Technology",
  "industry": "Consumer Electronics"
}
```

**Honesty note:** as of this writing, the portfolio components (holding form, table, import/export buttons) are implemented but there is **no portfolio page in the navigation** — the only routes are `/economics` and `/analytics`. The module works at the code level and its storage/JSON format is stable, but you cannot reach it from the UI yet.

Because storage is localStorage, clearing your browser data (or switching browsers/machines) wipes the portfolio. Export regularly if you care about the data.
